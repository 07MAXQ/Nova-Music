# Nova Music

**Неофициальный плеер для Яндекс Музыки на Windows.** Тёмная тема, синхронные тексты песен, эквалайзер, перенос плейлистов из других сервисов, «Слушать вместе».

> Nova Music — неофициальный клиент. ООО «Яндекс» к проекту отношения не имеет. Для работы нужен ваш собственный аккаунт Яндекс Музыки.

## Что умеет

- **Вход без пароля в приложении:** код и страница Яндекса, QR для телефона, несколько аккаунтов с быстрым переключением. Если вход не получился, Nova проверяет сеть и часы и подсказывает причину.
- **Звук:** плавные переходы, нормализация громкости, 10-полосный эквалайзер со своими профилями, эффект «как в зале», повтор отрезка A–B, продолжение длинных треков с места остановки, выбор устройства вывода.
- **Тексты песен** с подсветкой строк, переводом и транслитерацией (корейский, японская кана, кириллица), картинка с цитатой для соцсетей.
- **Перенос музыки** из Spotify, YouTube Music, SoundCloud, Last.fm («любимые» по имени пользователя и своему ключу API), текста, CSV и M3U: сопоставление с порогом уверенности, ручной выбор спорного, отчёт и откат одной кнопкой.
- **Библиотека:** единый поиск по лайкам, плейлистам и каталогу, фильтры и сохранённые подборки («Забытые любимые», «Недавно добавленное») с сохранением найденного плейлистом Яндекс Музыки, теги и заметки к трекам, экспорт плейлистов (txt, CSV, M3U, JSON), резервная копия лайков и плейлистов с восстановлением, поиск и удаление повторов, история прослушивания.
- **Статистика, отчёт за неделю и достижения:** картинка 9:16 или текст без имени аккаунта и времени суток; названия можно скрыть. 19 наград за прослушивание и освоенные возможности считаются на вашем компьютере и никуда не отправляются.
- **Оформление:** 11 тем, свой цвет, тема по времени суток, режим высокого контраста, настраиваемая боковая панель.
- **Окно:** запоминает размер и место, мини-плеер поверх окон (в том числе режим «только обложка»), глобальные горячие клавиши, системный трей, Discord Rich Presence. Управление с клавиатуры: Tab, стрелки в списках и меню, Ctrl+F6 между областями окна, Alt+↑ и Alt+↓ меняют порядок треков в плейлисте и очереди, стрелки перематывают в мини-плеере.
- **Слушать вместе** с друзьями. По желанию чат и реакции в комнате (выключены по умолчанию); хост может разрешить всем добавлять треки («вечеринка») или выбирать следующий голосованием.
- **Проверка целостности:** Nova сама проверяет свои настройки и сохранённые данные, исправляет то, что можно вернуть назад, и показывает, что сделала; одна кнопка откатывает исправленное, накопленное вами (история, заметки) без вашего согласия не трогается. Расписание выбираете вы, ничего не отправляется.

## Установка

Установщик (MSI) выкладывается в разделе **[Releases](https://github.com/07MAXQ/Nova-Music/releases)**. Пока там нет релиза, скачивать нечего.

1. Скачайте `.msi` из последнего релиза и запустите.
2. Windows может показать предупреждение SmartScreen («Неизвестный издатель»): установщик пока не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае», если вы скачали файл отсюда.
3. Войдите через Яндекс. Токен сохраняется в Диспетчере учётных данных Windows и никуда не отправляется, кроме API Яндекс Музыки.

Каждый релиз содержит контрольную сумму SHA-256 рядом с установщиком: сверьте её командой `Get-FileHash .\файл.msi -Algorithm SHA256` в PowerShell.

### Проверка обновлений

Nova ставит обновление, только если оно подписано ключом проекта. Отпечаток ключа можно сверить с тем, что показано в приложении (Настройки → О проекте → «Ключ подписи»):

```
38146D709620F594 · 52B7 FD93 EE1C 1807 9142 8F8E 29EC CE3B
```

Если отпечаток в приложении другой, не устанавливайте обновление и напишите сюда.

## Приватность

Nova может анонимно сообщать разработчику об ошибках: случайный номер установки (его короткий хэш показан в Настройки → Диагностика), версия, система и очищенный текст ошибки. Там же кнопка «Что именно отправляется» показывает, что уйдёт на сервер. В отчётах нет имени, почты, аккаунта Яндекса, названий треков и истории прослушивания. Отправку можно выключить одним переключателем.

## Вопросы и ошибки

Пишите в [Issues](https://github.com/07MAXQ/Nova-Music/issues) этого репозитория. Не вставляйте токены и пароли. Хэш установки (Настройки → Диагностика) помогает найти вашу ошибку, доступа к вашему аккаунту он не даёт.
